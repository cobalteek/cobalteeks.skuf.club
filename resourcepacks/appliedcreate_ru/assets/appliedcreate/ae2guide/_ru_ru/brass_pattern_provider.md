# Латунный шаблонный поставщик

<Row gap="20">
<Column>

<ItemImage id="appliedcreate:brass_pattern_provider" scale="4" />

Латунный шаблонный поставщик — это улучшенная версия <ItemLink id="appliedcreate:andesite_pattern_provider" />. Работает так же, но может хранить до **36 шаблонов обработки**, что делает его удобным для сложной автоматизации с большим количеством рецептов механической сборки.

</Column>
</Row>

## Особенности

- **36 слотов шаблонов** — в 4 раза больше, чем у андезитового варианта
- **Умное распределение по сетке** — автоматически сопоставляет рецепты и размещает ингредиенты в нужных слотах механических сборщиков; поддерживаются рецепты механической сборки Create и обычные формованные рецепты
- **Смещение рецепта** — рецепты меньшего размера корректно размещаются; слишком большие рецепты отклоняются
- **Полная интеграция с AE2** — режим блокировки, фиксация крафта, отображение в терминале шаблонов, приоритет и все стандартные функции поставщика шаблонов AE2
- **Режим направления** — ПКМ ключом переключает режим направления
- **Кабельная часть** — доступен как модуль для установки на кабель
- **Улучшение на месте** — можно улучшить андезитовый вариант с сохранением всех шаблонов

## Установка

1. **Постройте** массив механических сборщиков и соедините их ключом
2. **Установите** латунный шаблонный поставщик рядом с любым сборщиком
3. **Подключите** к ME-сети с помощью кабелей AE2
4. **Вставьте** до 36 шаблонов обработки

## Советы

- Используйте латунный шаблонный поставщик, если автоматизируете много разных рецептов механической сборки
- Кабельный вариант удобен для плотных ME-сетей
- Порядок входов в шаблоне не важен — сопоставление идёт по результату
- Можно разместить несколько поставщиков рядом с одним массивом сборщиков для увеличения количества шаблонов
