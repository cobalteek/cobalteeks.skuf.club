# Андезитовый шаблонный поставщик

<Row gap="20">
<Column>

<ItemImage id="appliedcreate:andesite_pattern_provider" scale="4" />

Андезитовый шаблонный поставщик — это специализированный поставщик шаблонов AE2 для механических сборщиков Create. Он может хранить до **9 шаблонов обработки** и автоматически распределяет ингредиенты по соседним механическим сборщикам в нужных позициях сетки.

</Column>
</Row>

## Особенности

- **9 слотов шаблонов** — хранит до 9 шаблонов обработки AE2
- **Умное распределение по сетке** — автоматически сопоставляет результат шаблона с рецептом и размещает каждый ингредиент в нужном слоте механического сборщика; поддерживаются рецепты механической сборки Create и обычные формованные рецепты
- **Смещение рецепта** — рецепты меньшего размера корректно размещаются в сетке; слишком большие рецепты отклоняются, чтобы избежать ошибок
- **Полная интеграция с AE2** — работает как обычное устройство сети AE2: режим блокировки, фиксация крафта, отображение в терминале шаблонов и приоритет
- **Режим направления** — ПКМ ключом переключает режим направления, как у обычного поставщика шаблонов AE2
- **Кабельная часть** — доступен как модуль для установки на кабель для компактных сборок
- **Улучшение** — можно улучшить до <ItemLink id="appliedcreate:brass_pattern_provider" /> с помощью <ItemLink id="appliedcreate:brass_pattern_provider_upgrade" />

## Установка

### В виде блока

1. **Постройте** массив механических сборщиков и соедините их ключом
2. **Установите** андезитовый шаблонный поставщик рядом с любым сборщиком
3. **Подключите** к ME-сети с помощью кабелей AE2
4. **Вставьте** шаблоны обработки в интерфейс поставщика

### В виде кабельной части

<ItemImage id="appliedcreate:andesite_pattern_provider_part" scale="2" />

Андезитовый шаблонный поставщик также доступен как кабельный модуль. Разместите его на стороне кабеля AE2 рядом с массивом механических сборщиков для более компактной сборки.

## Создание шаблонов обработки

Поставщик работает с **шаблонами обработки AE2**:

1. Откройте терминал шаблонов AE2
2. Переключитесь в режим **обработки**
3. Укажите **входы**, соответствующие ингредиентам рецепта механической сборки (порядок не важен — поставщик ориентируется по результату)
4. Укажите **результат** рецепта
5. Закодируйте шаблон и поместите его в поставщик

Когда система ME получает запрос на крафт, поставщик:

1. Запрашивает все необходимые материалы из сети
2. Определяет подходящий рецепт (механическая сборка или обычный формованный) по результату
3. Проверяет, помещается ли рецепт в соседнюю сетку сборщиков
4. Распределяет ингредиенты по слотам согласно раскладке рецепта
5. Запускает процесс сборки

## Улучшение

Используйте <ItemLink id="appliedcreate:brass_pattern_provider_upgrade" /> на андезитовом шаблонном поставщике, чтобы улучшить его до <ItemLink id="appliedcreate:brass_pattern_provider" /> с 36 слотами шаблонов. Все существующие шаблоны сохраняются.
