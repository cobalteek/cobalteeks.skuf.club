# P2P-туннель нагрузки

<Row gap="20">
<Column>

<ItemImage id="appliedcreate:stress_p2p_tunnel" scale="4" />

P2P-туннель нагрузки — это часть P2P-туннеля AE2, которая передаёт вращательную нагрузку Create (скорость и крутящий момент) через ME-сети. Он позволяет соединять кинетические сети без необходимости физического соединения валами.

</Column>
</Row>

## Основные возможности

- **Беспроводное соединение кинетики** — соединяйте удалённые кинетические сети Create через систему ME-кабелей
- **Полная передача вращения** — передаёт как скорость (RPM), так и нагрузку без потерь
- **Несколько выходов** — один входной туннель может питать несколько выходных, как и стандартные P2P-туннели
- **Стандартное поведение P2P** — используется с картами памяти и системой настройки AE2
- **Настройка предметами Create** — можно настроить, используя механические предметы Create (шестерни, валы и т.д.) рядом со стандартным ME P2P-туннелем

## Как это работает

1. **Разместите** два P2P-туннеля нагрузки на ME-кабелях AE2
2. **Свяжите** их с помощью карты памяти (как любой P2P-туннель AE2)
3. **Подключите** источник кинетики Create (вал, шестерня и т.д.) рядом с входным туннелем на стороне кабельной шины
4. **Подключите** потребитель кинетики Create рядом с выходным туннелем
5. Вращение передаётся через P2P-соединение так, как будто блоки находятся вплотную

## Советы по установке

- Части туннеля должны быть направлены наружу от кабельной шины к кинетическим блокам
- Убедитесь, что оба туннеля подключены к активной ME-сети (требуются каналы)
- Входной туннель — тот, который вы первым связали картой памяти
- Потерь скорости и нагрузки нет — передача 1:1

## Получение

P2P-туннель нагрузки можно получить, **настроив (attune)** стандартный <ItemLink id="ae2:me_p2p_tunnel" /> с помощью механического предмета Create (например, вала или шестерни). Возьмите механический предмет и нажмите ПКМ по P2P-туннелю, чтобы выполнить настройку.
