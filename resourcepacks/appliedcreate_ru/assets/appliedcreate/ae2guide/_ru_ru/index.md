# Applied Create

Applied Create объединяет механическую кинетику Create с автоматизацией Applied Energistics 2.

Мод добавляет специальные поставщики шаблонов для механической сборки, ячейки хранения нагрузки для ME-сети, P2P-туннели для передачи кинетической энергии и блоки-преобразователи, связывающие обе системы энергии.
